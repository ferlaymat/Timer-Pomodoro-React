# Timer-Pomodoro-React

This app is a sample which show how basic timer with interactive pauses.

## Requirements

- node: v24.13.1
- "bootstrap": "^5.3.8"
- "react": "^19.2.4"
- "react-dom": "^19.2.4"
- "react-router": "^7.14.1"
- "react-router-dom": "^7.14.1"

## Getting Started

```bash
cd ./timer-app
npm run dev
```
